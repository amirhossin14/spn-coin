# SPN Coin Network

This file lists the independent operators running SPN Coin nodes. Running a node
helps make the network genuinely decentralized. Thank you to everyone here. 🙏

> SPN Coin is an **educational network**. Running a node is a learning and
> contribution activity — it involves no money and the coin has no value.

---

## How to join

Running a node takes about 5 minutes:

```bash
git clone https://github.com/<YOUR_USER>/spn-coin.git
cd spn-coin
npm install --omit=dev
bash scripts/join-network.sh http://<SEED_ADDRESS>:3000
```

Full instructions: [`docs/VPS_SEED_NODE_GUIDE.md`](./docs/VPS_SEED_NODE_GUIDE.md)
(for an always-on node) or run it locally to experiment.

Once you're running, open a pull request adding yourself to the table below.
