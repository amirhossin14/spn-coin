# Security Policy

SPN Coin is an **educational blockchain project with no monetary value**.
We still take security seriously and welcome responsible disclosure.

## Reporting a Vulnerability

Please report security issues privately, **not** as public GitHub issues:

- Open a private advisory: `Security → Advisories → New draft advisory`
- Or email: security@spncoin.example

Include: a description, steps to reproduce, affected version/commit, and
impact. We aim to acknowledge reports within **72 hours**.

## Scope

In scope: the blockchain node, HTTP API, wallet/token logic, and the web UI.
Out of scope: the example CDN dependencies, and any deployment you run
yourself with modified configuration.

## Supported Versions

As an educational project, only the latest `main` branch is supported.

## Disclosure

We credit reporters in the published advisory unless you prefer to remain
anonymous. As an educational project we have no paid bug bounty.
