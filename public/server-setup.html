Real Server Setup Guide
1
Server requirements
Minimum: 2 vCPU · 2 GB RAM · 20 GB SSD · Ubuntu 22.04
Recommended: 4 vCPU · 8 GB RAM · 100 GB NVMe
Providers: Hetzner (€4/mo) · DigitalOcean · Contabo · AWS EC2
2
Install Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
node --version   # Should print v20.x.x
Copy
3
Upload & install the node
# From your local machine — upload the zip
scp SPN Coin_v6_Final.zip user@YOUR_SERVER_IP:/home/user/

# On the server
unzip SPN Coin_v6_Final.zip
cd SPN Coin_v6
npm install --production
Copy
4
Create .env file
Generate two random secrets first:
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# Run twice — save both outputs
Copy
cp .env.example .env
nano .env
Copy
NODE_ENV=production
PORT=3000
STRATUM_PORT=3333
CHAIN_ID=1
JWT_SECRET=<first-random-secret>
JWT_REFRESH_SECRET=<second-random-secret>
ANTHROPIC_API_KEY=sk-ant-api03-...
DATABASE_URL=postgresql://user:pass@localhost:5432/spncoin
PEER_URLS=https://node2.example.com,https://node3.example.com
Copy
5
PostgreSQL setup (for persistent state)
sudo apt install -y postgresql postgresql-contrib
sudo -u postgres psql -c "CREATE USER spncoin WITH PASSWORD 'strongpassword';"
sudo -u postgres psql -c "CREATE DATABASE spncoin OWNER spncoin;"
# Then set DATABASE_URL in .env
Copy
Or use Neon.tech (free hosted PostgreSQL) — create a project at neon.tech and copy the connection string directly into .env
6
Run with PM2 (process manager)
sudo npm install -g pm2
pm2 start server.js --name spncoin-node
pm2 save
pm2 startup   # Follow the printed command to auto-start on reboot
Copy
# Useful PM2 commands
pm2 logs spncoin-node       # View live logs
pm2 restart spncoin-node    # Restart
pm2 status                 # Check status
Copy
7
Nginx reverse proxy + SSL (HTTPS)
sudo apt install -y nginx certbot python3-certbot-nginx
sudo nano /etc/nginx/sites-available/spncoin
Copy
server {
    listen 80;
    server_name your-domain.com;

    # HTTP API + Dashboard
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
Copy
sudo ln -s /etc/nginx/sites-available/spncoin /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d your-domain.com   # Free SSL
Copy
After SSL is set up, miners connect via: wss://your-domain.com/stratum
8
Firewall rules
sudo ufw allow ssh
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS (Nginx)
sudo ufw allow 3000/tcp  # Node.js direct (optional)
sudo ufw allow 3333/tcp  # Stratum dedicated port (optional)
sudo ufw enable
Copy

docker-compose -f docker-compose.prod.yml up -d
