Run a Node & Mine

● Mainnetv—
Help decentralize SPN. The more independent nodes and miners join, the stronger and more decentralized the network becomes. This page shows how to mine SPN Coin and how to run your own full node. SPN is an educational network under testing — mined coins currently carry no monetary value.

SPN Coin is a SHA-256d proof-of-work blockchain — the same family as Bitcoin. That means you can mine it with CPU (for learning) or standard SHA-256 hardware, and anyone can run a full node to help secure and decentralize the chain.

Part 1 — Mine SPN Coin

Mining is how new blocks are produced and how the network stays secure. You point a miner at the SPN mining pool and get rewarded in SPN for every block your work helps find.

1Get an SPN address

You need an address to receive mining rewards. Create one in the Wallet page — it looks like SPN1…. Your private key stays in your browser and is never sent to the server.

2Connect a miner to the pool

SPN runs a Stratum mining pool over WebSocket. Point any SHA-256d Stratum miner at the pool endpoint below, using your SPN address as the username:

# Pool endpoint (Stratum over WebSocket)
wss://spnchain.com/stratum

# Username: your SPN address   ·   Password: x (anything)
username: SPN1yourAddressHere
password: x
New to mining? The dashboard's Mining page has a built-in browser/CPU miner you can start with a single click — perfect for testing on this educational network.

3Watch your rewards

Open the Dashboard or Addresses page and search your SPN address. Each block you help mine adds 50 SPN (until the next halving at block 210,000).

Part 2 — Run a full node

A full node stores and verifies the whole chain and relays blocks to other nodes. Every independent node makes SPN more decentralized and resilient. You can run one on a small Linux server or even your own computer.

1Requirements

A Linux machine (a small VPS or your own PC) with Node.js 20 or newer. Check with:

node --version   # should print v20.x or higher

If it's missing, install from nodejs.org or your package manager.

2Get the node software

Download the SPN Coin node package (the same release the network runs) and unzip it, then enter the folder:

unzip SPN_Coin.zip -d spn-node
cd spn-node

3Join the network

Point your node at a seed node and let it sync. The project provides a helper script — pass the seed URL you were given by the network operator:

bash scripts/join-network.sh http://SEED_IP:3000

The script installs dependencies, creates a .env with your PEER_URLS, and starts syncing the chain from the network.

Ask the network operator for the current seed node URL. Your node connects out to the seed, so a home node behind a router works without any port forwarding.

4Keep it running (recommended)

Use PM2 so the node restarts automatically and survives reboots:

npm install -g pm2
pm2 start server.js --name spn-node
pm2 save && pm2 startup

5Accept inbound peers (optional, for seed operators)

If you want other nodes to connect to yours, open the P2P port in your firewall so it's reachable:

# SPN P2P port
ufw allow 8333/tcp
Only do this if you intend your node to act as a public seed. A normal home node that only connects outward does not need any open ports.

6Confirm it's syncing

Check your node's health locally — the height should climb toward the network's current height:

curl -s http://localhost:3000/api/health
Reference parameters — P2P port: 8333 · API/HTTP port: 3000 · Consensus: SHA-256d · Block time: 10 min · Reward: 50 SPN · Halving: every 210,000 blocks.
