Project Roadmap

Whitepaper ● Mainnet v—
An honest note. SPN Coin is an educational, Bitcoin-inspired blockchain built from scratch. It currently has no monetary value, is not a security or investment, and makes no promise of profit or returns. This roadmap describes engineering milestones and goals — dates are targets, not guarantees.

SPN Coin is a full proof-of-work, UTXO blockchain (SHA-256d, 10-minute blocks, 21,000,000 fixed supply, halving every 210,000 blocks). The goal of this roadmap is total transparency: what has been built, what we are doing now, and where the project is headed over the next one year and five years.

✓

Phase 0 — Foundation

Completed · the core chain
✓
Real proof-of-work consensus

Full 256-bit integer targets (not a "count the zeros" shortcut), cumulative-work fork choice, Median-Time-Past (BIP-113), and difficulty retargeting.

✓
UTXO ledger + script engine

Bitcoin-style UTXO model with apply/undo, Merkle trees and proofs, and a script engine supporting P2PKH, multisig and timelocks.

✓
Halving economics

Fixed 21,000,000 SPN maximum supply, 50 SPN initial block reward, halving every 210,000 blocks — no hidden minting.

✓
P2P networking + mining pool

Peer-to-peer gossip layer (raw socket + HTTP), a Stratum mining pool, and a token layer for issuing assets on the base chain.

✓
Web ecosystem & tooling

Block explorer, dashboard, HD wallet (BIP39), CLI wallet, threat radar, and a full test suite with CI/CD.

✓

Phase 1 — Security & Network Hardening

Recently completed
✓
Client-side wallet signing (critical fix)

The most important security change: private keys and the 12-word phrase are now generated and signed entirely in the browser and never sent to the server. This closed the single critical flaw that previously existed.

✓
Advanced peer discovery & anti-eclipse

Bitcoin-inspired address manager (tried/new tables, /16 network-group spread), exponential backoff, and persistence across restarts.

✓
DoS protection & ban scoring

Per-peer token-bucket rate limiting per message type, misbehavior scoring with 24-hour bans, and graceful score decay.

✓
Headers-first fast sync + pruning

Header chain downloaded and validated first, then block bodies fetched in parallel; optional pruning with an 80-byte compact header codec.

✓
Server & app hardening

SSH key-only login (password login disabled), IDS/IPS, rate limiting, role-based access control, SSRF guards, JWT + 2FA (TOTP), and a redesigned public explorer.

◆

Phase 2 — Where we are now

In progress
•
From one node to many

Today the network runs primarily on one node (peers = 0). Bringing up additional independent nodes is the current focus so the chain becomes genuinely distributed.

•
Stable public testnet + faucet

Standing up a durable public testnet so anyone can connect a node, mine, and transact — the real field test for the new networking modules.

•
Complete independent header validation

Finishing validateHeader so every node fully verifies the header chain on its own.

Is publishing this roadmap safe?

Yes — technically. This page shows only public information (project plans and milestones). It exposes no keys, passwords, or user data, and needs no login. Publishing a transparent roadmap is normal and actually builds trust with users and exchanges.

One thing to keep right: a roadmap must never turn into a financial promise. This page deliberately avoids any mention of price, profit, guaranteed returns, or "invest now" language — because those claims can create real legal risk (securities law) and mislead people. Keeping the roadmap about technology and milestones, with the honest notice at the top, is both the safest and the most credible approach.

In short: transparency about what you build is good and safe; promises about what people will earn are not. This roadmap stays firmly on the safe side.
