# راهنمای آدرس اختصاصی SPN Coin

آدرس‌های این بلاکچین کاملاً قابل‌تنظیم‌اند. همهٔ تنظیمات در `config.js` →
بلوک `ADDRESS` است. تغییر هرکدام **شکنندهٔ اجماع** است: دادهٔ زنجیره و آدرس‌های
قبلی بی‌اعتبار می‌شوند، پس قبل از استفاده `./data` را پاک و روی testnet تازه،
بلاک جنسیس را دوباره ماین کن.

## ۱) عوض‌کردن پیشوند/برند (ساده‌ترین)
در `config.js`:
```js
PREFIX_MAINNET: 'PARS1',   // مثلاً
PREFIX_TESTNET: 'PARSt',
```
نتیجه: آدرس‌ها به‌شکل `PARS1B...` می‌شوند.

## ۲) سبک bech32 مدرن (حروف کوچک، checksum قوی‌تر)
```js
FORMAT:      'bech32',
HRP_MAINNET: 'pars',
HRP_TESTNET: 'tpars',
```
نتیجه: آدرس‌ها به‌شکل `pars1q...` می‌شوند (شبیه آدرس‌های SegWit بیت‌کوین / Cosmos).

## ۳) ریبرند کامل کوین
نام و نماد در `config.js` → `COIN`:
```js
NAME: 'ParsCoin', SYMBOL: 'PARS', ADDRESS_PREFIX: 'PARS',
```
به‌علاوهٔ پیشوند/HRP بالا. (نسخهٔ توکن L2 در `contracts/` هم نام/نماد جدا دارد.)

## ۴) آدرس vanity (کاراکترهای اول دلخواه)
ابزار brute-force کلید:
```bash
npm run vanity -- SPN1BCool          # آدرس با SPN1BCool شروع شود
npm run vanity -- SPN1BAli --max=20000000
npm run vanity -- pars1qcool --regex # برای bech32 / تطبیق دلخواه
```
نکتهٔ مهم (base58check): چون بایت نسخه ثابت است، **اولین کاراکتر بعد از پیشوند
محدود است** (مثلاً با `0x19` همیشه `B`). پس الگوی دلخواهت باید با همان کاراکتر
شروع شود؛ وگرنه ناممکن است. هر کاراکتر ثابت اضافه، کار را ~۳۳ تا ۵۸ برابر می‌کند:
۳–۴ کاراکتر در حد ثانیه، ۵–۶ دقیقه/ساعت، ۷+ تک‌رشته‌ای غیرعملی.

> کلید خصوصی‌ای که ابزار چاپ می‌کند را امن نگه دار — هرکس آن را داشته باشد مالک آدرس است.

## ساختار فنی آدرس
کلید عمومی → `SHA256` → `RIPEMD160` (HASH160، ۲۰ بایت) → بسته به فرمت:
- **base58check**: `version-byte || HASH160` با checksum دوبل-SHA256، و پیشوند برند جلوش.
- **bech32**: کدگذاری ۵-بیتی HASH160 تحت HRP با checksum BIP173.
